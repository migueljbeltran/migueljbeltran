## Profile

```txt
focus       full-stack software engineering
strengths   polished interfaces, backend services, data workflows, tested systems
current     Assistant Technical Director at ASUCD Picnic Day
style       practical builder, careful debugger, product-minded teammate
```

I like building tools that make complicated things easier to use. Recent work spans a live UC Davis Picnic Day platform for 70,000+ yearly attendees, a Deadlock analytics app used by 1,000+ users, and a machine learning classifier over 32,000+ Spotify tracks.

I am most at home where the frontend, backend, data, and tests all meet: React and TypeScript interfaces, Java/Spring Boot or Python/FastAPI services, reliable data models, and user-facing features that have to hold up outside a demo.
